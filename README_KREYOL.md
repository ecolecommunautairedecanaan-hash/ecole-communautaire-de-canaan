# École Communautaire De Canaan

Sit entènèt lekòl la — HTML, CSS ak JavaScript.

## Ouvri sou òdinatè w
1. Ekstrè fichye ZIP la.
2. Louvri dosye `ecole_communautaire_de_canaan`.
3. Double-klike sou `index.html` pou wè sit la nan navigatè w.

## Anvan ou pibliye l
Ranplase enfòmasyon sa yo nan `index.html`:
- `[Mete adrès lekòl la]`
- `[Mete nimewo telefòn lan]`
- `[Mete adrès imèl la]`
- Konfime nivo lekòl la ofri yo.
- Mete foto reyèl lekòl la sèlman si gen otorizasyon pou pataje yo.

## Pibliye gratis sou GitHub Pages
1. Kreye yon kont sou https://github.com/
2. Kreye yon nouvo repository piblik, pa egzanp `ecole-communautaire-de-canaan`.
3. Telechaje `index.html`, `style.css`, ak `script.js` nan repository a.
4. Ale nan **Settings → Pages**.
5. Nan **Build and deployment**, chwazi **Deploy from a branch**.
6. Chwazi branch `main`, folder `/ (root)`, epi peze **Save**.
7. Tann GitHub kreye lyen sit la. Ou ka pataje lyen sa a ak tout moun.

Sit la itilize yon font Google Fonts lè entènèt disponib; rès sit la ap toujou fonksyone san li.
